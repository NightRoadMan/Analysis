# Витрина анализов: прототип

Кликабельный прототип мобильной витрины анализов НаПоправку: каталог, деталька анализа, деталька клиники и лаборатории, корзина, карта лабораторий, оформление и оплата, «Мои записи» с заказом анализов. Светлая и тёмная темы переключаются над телефоном.

Открыть: https://nightroadman.github.io/Analysis/

## Как устроено

`index.html` собран из исходников в `src/` и не требует сервера: стили, скрипты и картинки внутри файла.

- `src/build/shell.html` разметка экранов с плейсхолдерами;
- `src/build/app.css` стили и токены тем;
- `src/build/app.js` логика экранов, корзины и карты;
- `src/build/clinic.js` деталька клиники, лаборатории и поликлиники ОМС (вставляется в `app.js` на месте `/*@@MODULES@@*/`);
- `src/build/orders.js` вкладка «Мои записи»: карточка заказа, детали, статусы;
- `src/build/parts.json` разметка из Figma, моковые анализы, иконки и логотипы;
- `src/assets/` иллюстрации из Paper, `src/assets/clinic/` фото клиник и карты для деталек.

Пересборка после правок:

```
python3 src/build/assemble.py index.html
```

Сверху есть переключатель «Свободно / Сценарии». В свободном режиме прототип ходится как обычно. В режиме «Сценарии» справа появляется панель с восемью сценариями по CJM (каталог, поиск, категория и деталька, карта, оформление, деталька клиники, «Мои записи», платёж не прошёл): шаги отмечаются сами, когда их проходишь, следующее нажатие подсвечивается на экране, а тап по шагу переносит прямо к нему.

Для демо можно открыть сразу нужный экран: `#analyses` (витрина), `#cat-vitamins` (категория), `#all` (поиск по анализам), `#search` (общий поиск), `#cart`, `#map`, `#lab`, `#pat` (данные пациента), `#res` (согласие на результаты), `#ok` (успешная оплата), `#clinic` (клиника с выбранным анализом), `#clinic-lab` (лаборатория), `#free` (поликлиника ОМС), `#orders` («Мои записи»), `#order` (детали заказа). На экранах «Моих записей» над телефоном появляется список «Статус заказа»: им переключаются все 11 статусов из макета.

Цены, лаборатории и адреса демонстрационные.

Pages публикуется из ветки `gh-pages`: после изменений в `main` отправьте её и туда (`git push origin main:gh-pages`).
