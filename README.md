# Витрина анализов: прототип

Кликабельный прототип мобильной витрины анализов НаПоправку: каталог, деталька, корзина, карта лабораторий, оформление и оплата. Светлая и тёмная темы переключаются над телефоном.

Открыть: https://nightroadman.github.io/Analysis/

## Как устроено

`index.html` собран из исходников в `src/` и не требует сервера: стили, скрипты и картинки внутри файла.

- `src/build/shell.html` разметка экранов с плейсхолдерами;
- `src/build/app.css` стили и токены тем;
- `src/build/app.js` логика экранов, корзины и карты;
- `src/build/parts.json` разметка из Figma, моковые анализы, иконки и логотипы;
- `src/assets/` иллюстрации из Paper.

Пересборка после правок:

```
python3 src/build/assemble.py index.html
```

Сверху есть переключатель «Свободно / Сценарии». В свободном режиме прототип ходится как обычно. В режиме «Сценарии» справа появляется панель с шестью сценариями по CJM (каталог, поиск, категория и деталька, карта, оформление, платёж не прошёл): шаги отмечаются сами, когда их проходишь, следующее нажатие подсвечивается на экране, а тап по шагу переносит прямо к нему.

Для демо можно открыть сразу нужный экран: `#analyses` (витрина), `#cat-vitamins` (категория), `#all` (поиск по анализам), `#search` (общий поиск), `#cart`, `#map`, `#lab`, `#pat` (данные пациента), `#res` (согласие на результаты), `#ok` (успешная оплата).

Цены, лаборатории и адреса демонстрационные.

Pages публикуется из ветки `gh-pages`: после изменений в `main` отправьте её и туда (`git push origin main:gh-pages`).
